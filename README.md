## 👑 Батя проекта и Наследие (Credits)

Этот проект — результат любви к пиксель-пёрфект эстетике и слияния двух легендарных веток:
1. **[mihailkotovski/DynamicIsland](https://github.com/mihailkotovski/DynamicIsland)** — безусловный **Батя проекта**. Михаил Котов в одиночку сотворил чудо: математическую кинематику пружин (Spring physics), слияние векторных капель (Goo effect), GPU-размытие через Windows Composition API, перетекание обложек и геометрию сквирклов на чистом C# WPF без единого стороннего NuGet-пакета. Снимаем шляпу и кланяемся в пояс!
2. **[NeoKirilX/DynamicIsland-Roc](https://github.com/NeoKirilX/DynamicIsland-Roc)** — амбициозный порт на функциональном языке Roc под Linux/Wayland, откуда в этот Windows-релиз перекочевал **весь колоссальный арсенал уникальных фич**, сохранив при этом оригинальный божественный интерфейс и 120 FPS плавность.

## 📜 Чанджлог: Что изменилось по сравнению с оригинальным форком Михаила Котова?

Оригинальный остров Михаила был потрясающим произведением искусства, но в нем не хватало кастомизации, поддержки разного железа и практических фич на каждый день. В версии **v1.0.0** мы превратили его в настоящий швейцарский нож:

### 1. 🪟 Движок стекла LiquidGlass (Жидкое vs Материальное)
* **Переключатель режимов стекла на лету:** В меню «Оформление» добавлен выбор между **«Жидким»** (глубокое линзовое преломление 1.085x, сияющий блик, хроматические края) и **«Материальным»** (матовое молочное матовое стекло с плотным рассеиванием).
* **Стеклянный ползунок (White Glass Knob):** Белая пилюля слайдера громкости и настроек теперь *всегда* одета в стекло — увеличивает дорожку под собой как стеклянная лупа, имеет полупрозрачное тело и зеркальную фаску.
* **Стеклянные табы (LiquidGlassTabs):** Все переключатели и сегменты получили физику растяжения объема при перетягивании, упругий сжатый край и стеклянный отблеск.
* **iOS 26 Liquid Glass Menu для выбора языка:** Выпадающее меню языков переработано с нуля — дымчатое стекло `#F01C1F2E` к `#E612141F`, градиентный безель, мягкие тени и упругий shockwave-отскок (`BackEase`).

### 2. 📱 Челка AMOLED (Notch) vs Парящая Пилюля (Pill)
* **Настоящая челка iPhone (`Squircle.Notch`):** Монолитный вырез, плавно вытекающий из верхней кромки экрана с кубическими кривыми Безье у основания («ушки»). Чернее самой черной дыры на AMOLED/OLED экранах.
* **Честный режим Пилюли:** Если включен режим пилюли (`Notch = false`), таймер и запись не прилипают костыльно к плееру, а летают **отдельным независимым островком-спутником** с аккуратным физическим зазором. В режиме челки — монолитно объединены в одно целое.

### 3. ⚡ Горячая загрузка конфигов Drag & Drop (Новинка!)
* **Кинул файл на остров — применился моментально:** Просто перетащите `.dni` или `.json` файл пресета на остров мышью — настройки, цвета, масштаб, позиция и стекло применятся на лету с красивым тостом «Конфиг применен».
* **Запуск из полки:** Плитки конфигов, лежащие на Полке (`Shelf`), теперь применяются по одному клику!
* **Запуск с аргументом:** `DynamicIsland.exe "my_preset.dni"` автоматически подхватывает файл при старте.

### 4. 🔌 Детектор флешек и накопителей (USB Device Notifications)
* Остров теперь слушает сырые системные сообщения Windows (`WM_DEVICECHANGE`, `DBT_DEVICEARRIVAL`, `GUID_DEVINTERFACE_DISK`, `GUID_DEVINTERFACE_VOLUME`).
* Вставили флешку, внешний SSD или подключили телефон? Даже если диск разбит на несколько скрытых разделов или еще не смонтирован проводником — остров моментально покажет красивое уведомление с иконкой диска!

### 5. 🎵 Музыкальный бронепоезд и Adlib-Proof караоке
* **Мгновенный Spotify:** Остров моментально реагирует на смену песни в Spotify без полуторасекундной тупежки благодаря комбинированному опросу Windows Media Manager.
* **Караоке ComboEngine:** Повторяющиеся припевы складываются в счетчик комбо (`x2`, `x3`, `x4`...) с 7 стилями на выбор.
* **Иммунитет к рэперским эдлибам:** Очищает мусор вроде `(skrrt)`, `(yeah)` и `(у)`, не сбивая комбо-серию.
* **Никаких наложений текста на эквалайзер:** Строка песни строго знает свои границы и никогда не перекрывает пляшущие полоски эквалайзера.
* **Инвертированные жесты:** Полноценный тумблер в настройках — свайп вправо включает следующий трек, свайп влево — предыдущий!
* **Клик по обложке:** Мгновенно вытаскивает окно плеера на передний план (`RaisePlayer`).

### 6. 🎛️ Полный эквалайзер и визуальные темы
* Настраиваемое количество полос эквалайзера (от 3 до 16).
* Режим точек (Dots mode) для компактного и мини-эквалайзера.
* Регулировка чувствительности эквалайзера в процентах.
* Анимированный неоновый дождь Матрицы (настройка плотности, скорости, количества строк и прозрачности).
* Космический фон звезд под музыку.

### 7. ⏱️ Прокачанный Таймер и OBS Studio
* Таймер больше не обрезается на значениях от 1 часа и более (`1:10:59`) — пилюля динамически расширяется до 98 px, а большой таймер до 368 px.
* Пресеты таймера, интервальный режим и режим овертайма.
* Полноценная интеграция с OBS Studio через WebSocket: индикатор записи, время записи, пауза и стоп.

### 8. 📐 Свободное позиционирование и защита от улетания
* Привязка к краям: **Слева**, **По центру**, **Справа** с физическим ограничением стен экрана.
* Точная настройка координат XY (стрелками клавиатуры с шагом 1px при зажатом Shift).
* **Модальное окно подтверждения в стиле iOS:** При перемещении острова появляется затемнение и подтверждение позиции. Если остров случайно улетел за экран дальше чем на 200px — сработает автоматический откат безопасности!

### 9. 👁️ Инструменты OCR и QR-сканер
* Захват экрана и области с распознаванием текста прямо на полку.
* Мгновенный генератор QR-кодов в один клик.

## 🎮 Управление для профессионалов

| Действие | Что происходит |
|---|---|
| **Левый клик по острову** | Раскрыть плеер / таймер / свернуть обратно |
| **Потянуть каплю вниз** | Упругая желейная физика растяжения: потяни и отпусти |
| **Свайп влево / вправо** | Переключение треков с физическим выталкиванием обложки |
| **Клик по обложке** | Вытащить играющее приложение на передний план (`RaisePlayer`) |
| **Правый клик** | Главное меню (Таймер, Полка, Оформление, Настройки) |
| **Средний клик (колесико)** | Остров тактично сваливает в туман на 5 секунд |
| **Колесо мыши над островом** | Плавная регулировка системной громкости |
| **Колесо мыши над плеером** | Регулировка громкости *только текущего играющего приложения* |
| **Ctrl + Колесо мыши** | Быстрое переключение источников звука (Spotify ⇄ Браузер ⇄ Яндекс) |
| **Перетаскивание `.dni`/`.json` на остров** | **Мгновенное применение конфигурации на лету** |
| **Перетаскивание любых файлов на остров** | Быстрое сохранение файлов на Полку |
| **Перетаскивание файла с Полки** | Перетаскивание напрямую в Telegram, Discord или проводник |

## 💾 Горячая загрузка конфигов (.dni / .json)

Настроили идеальный неоновый остров с нужными координатами, челкой и жидким стеклом?
* **Экспорт:** В меню «Настройки» нажмите **«Экспорт настроек»** — создастся готовый файлик `.dni`.
* **Горячий импорт:** Перетащите файл `.dni` прямо на островок мышкой, либо откройте его через проводник — остров мгновенно перестроится прямо у вас на глазах без перезапуска!

## 🛠️ Сборка из исходников

Для самостоятельной компиляции понадобится только **.NET 8 SDK** (Windows 10 / 11):

```powershell
# 1. Клонируем репозиторий
git clone https://github.com/NeoKirilX/DynamicIsland.git
cd DynamicIsland

# 2. Собираем единый автономный бинарник
dotnet publish DynamicIsland.csproj -c Release -r win-x64 --self-contained -o ./bin/Publish

# 3. Запускаем готовый exe
./bin/Publish/DynamicIsland.exe
```

Никакого стороннего хлама, никаких драйверов, установка не требуется — скачал и кайфуешь.
